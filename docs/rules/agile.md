EPIC 1 
Nama EPIC: Onboarding & Diagnostic
Tujuan EPIC: Mempermudah pengguna baru (siswa & orangtua) memulai penggunaan dan memperoleh baseline kompetensi untuk personalisasi jalur belajar.

Sebagai siswa
Saya ingin mendaftar dan melengkapi profil belajar singkat (jenjang, mata pelajaran, waktu belajar) pada pertama kali masuk
Agar sistem bisa merekomendasikan materi yang relevan dan sesuai tingkat saya

Sebagai siswa
Saya ingin mengikuti tes diagnostik singkat saat pertama kali (15–20 soal)
Agar platform mengetahui area kelemahan dan kekuatan saya

Sebagai orangtua
Saya ingin mengaktifkan akun anak dengan persetujuan dan batasan waktu penggunaan
Agar saya dapat memantau aktivitas belajar anak dan menjaga keamanan

EPIC 2 
Nama EPIC: Lesson Generation & Consumption (Experience)
Tujuan EPIC: Menyediakan materi pembelajaran yang mudah dicerna, ringkas, dan langsung dapat diakses oleh siswa kapan saja.

User Stories:

Sebagai siswa
Saya ingin meminta materi singkat tentang topik tertentu dan segera mendapat penjelasan yang mudah dimengerti
Agar saya bisa belajar topik baru tanpa menunggu guru

Sebagai siswa
Saya ingin melihat materi dalam format langkah demi langkah (micro-lessons) dengan contoh soal
Agar saya dapat memahami satu konsep sebelum lanjut ke yang berikutnya

Sebagai siswa
Saya ingin menandai materi sebagai favorit atau menyimpan untuk belajar berikutnya
Agar saya mudah mengulang materi yang penting

Sebagai siswa
Saya ingin melihat indikator tingkat kesulitan dan estimasi durasi membaca setiap lesson
Agar saya bisa memilih materi yang sesuai waktu belajar saya

EPIC 3 
Nama EPIC: Tutor Chat & On-demand Help
Tujuan EPIC: Memberikan pendampingan responsif saat siswa bertanya, membantu klarifikasi konsep dan problem solving.

User Stories:

Sebagai siswa
Saya ingin bertanya satu pertanyaan tentang materi dan mendapat jawaban yang relevan beserta contoh
Agar saya cepat paham ketika menemui kebingungan

Sebagai siswa
Saya ingin mendapat penjelasan yang disesuaikan dengan tingkat saya (lebih sederhana atau lebih rinci)
Agar jawaban lebih mudah saya cerna

Sebagai siswa
Saya ingin menerima referensi atau sumber jika jawaban membutuhkan rujukan
Agar saya bisa mempelajari lebih dalam atau memverifikasi jawaban

Sebagai siswa
Saya ingin mampu menandai jawaban sebagai membantu/tidak membantu
Agar platform dapat menyesuaikan kualitas jawaban di masa depan

Epic 4 
Nama EPIC: Practice & Assessment Experience
Tujuan EPIC: Menyediakan latihan yang efektif dan umpan balik formatif untuk memperkuat penguasaan kompetensi.

User Stories:

Sebagai siswa
Saya ingin mengerjakan kuis singkat setelah setiap lesson dan mendapat feedback instan
Agar saya tahu bagian mana yang belum dikuasai

Sebagai siswa
Saya ingin mendapat penjelasan kenapa jawaban saya salah dan langkah perbaikan singkat
Agar saya bisa memperbaiki kesalahan konsep, bukan hanya menebak jawaban

Sebagai siswa
Saya ingin melihat ringkasan kesalahan yang paling sering saya lakukan
Agar saya dapat fokus berlatih pada kelemahan utama

EPIC 5 
Nama EPIC: Personalized Learning Path (Learner Journey)
Tujuan EPIC: Menyediakan jalur belajar yang adaptif dan relevan berdasarkan kemampuan dan progres siswa.

User Stories:

Sebagai siswa
Saya ingin mendapat rekomendasi urutan materi berdasarkan hasil diagnostik dan performa kuis terakhir
Agar saya belajar secara terstruktur dan efisien

Sebagai siswa
Saya ingin memilih untuk mengikuti jalur rekomendasi otomatis atau menyusun jalur belajar sendiri
Agar saya tetap punya kontrol atas proses belajar saya

Sebagai siswa
Saya ingin mendapat notifikasi rekomendasi remedial jika performa turun pada topik tertentu
Agar saya dapat segera memperbaiki kelemahan

Sebagai orangtua
Saya ingin melihat ringkasan jalur belajar anak dan rekomendasi tindak lanjut yang sederhana
Agar saya bisa membantu memotivasi dan mendukung anak

EPIC 6
Nama EPIC: Progress, Mastery & Motivation
Tujuan EPIC: Menyajikan metrik kemajuan yang memotivasi dan memudahkan siswa mengukur penguasaan kompetensi.

User Stories:

Sebagai siswa
Saya ingin melihat dashboard progress pribadi yang menampilkan topik yang sudah dikuasai dan yang perlu diulang
Agar saya tahu kemajuan saya secara nyata

Sebagai siswa
Saya ingin mendapat lencana atau indikator pencapaian kecil saat menyelesaikan milestone
Agar saya merasa termotivasi melanjutkan belajar

Sebagai siswa
Saya ingin opsi untuk menetapkan tujuan belajar mingguan dan melihat progress terhadap tujuan itu
Agar saya belajar dengan tujuan yang jelas

EPIC 7
Nama EPIC: Content Trust, Transparency & Feedback Loop
Tujuan EPIC: Membangun kepercayaan pengguna melalui transparansi sumber, confidence indicators, dan mekanisme pelaporan.

User Stories:

Sebagai siswa
Saya ingin melihat indikasi kepercayaan (confidence) dan sumber rujukan setiap materi/jawaban
Agar saya bisa menilai seberapa akurat dan dapat dipercaya informasi itu

Sebagai siswa
Saya ingin mudah menandai/ melaporkan materi atau jawaban yang salah atau kurang tepat
Agar konten yang keliru cepat ditindaklanjuti

Sebagai admin/platform
Saya ingin menerima ringkasan item yang sering dilaporkan agar bisa difokuskan untuk perbaikan
Agar kualitas platform meningkat berdasarkan masukan nyata

Sebagai siswa
Saya ingin melihat riwayat tindakan pada laporan (mis. sedang diperiksa / diperbaiki)
Agar saya tahu laporan saya diperhatikan dan ditindaklanjuti

EPIC 8
Nama EPIC: User Support & Help Resources
Tujuan EPIC: Menyediakan panduan, tutorial, dan support channel agar pengguna dapat memaksimalkan pengalaman belajar.

User Stories:
Sebagai siswa
Saya ingin akses ke panduan singkat cara penggunaan platform dan tips belajar
Agar saya tidak bingung memulai dan belajar lebih efektif

Sebagai siswa
Saya ingin mendapat bantuan via FAQ atau chat support bila menemui masalah non-akademik (akun, pembayaran, dsb.)
Agar masalah cepat terselesaikan dan tidak mengganggu proses belajar

Sebagai admin/platform
Saya ingin mencatat jenis pertanyaan/masalah yang sering muncul untuk perbaikan UX
Agar platform lebih intuitif dan membutuhkan lebih sedikit dukungan manual

EPIC 9
Nama EPIC: Account, Privacy & Parental Controls
Tujuan EPIC: Menjamin perlindungan data pengguna (terutama anak) dan memberikan kontrol yang jelas kepada orangtua.

User Stories:

Sebagai siswa
Saya ingin menghapus atau menonaktifkan akun dengan panduan langkah demi langkah
Agar saya memiliki kontrol atas data pribadi saya

Sebagai admin/platform
Saya ingin menerapkan penyimpanan dan retensi data sesuai kebijakan privasi yang jelas
Agar kepatuhan dan kepercayaan pengguna terpenuhi
