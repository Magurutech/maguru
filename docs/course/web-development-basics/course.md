# Web Development Basics

Selamat datang di course Web Development Basics! Course ini dirancang untuk pemula yang ingin mempelajari fundamental web development.

## Apa yang akan Anda pelajari?

Di course ini, Anda akan belajar:
- **HTML5**: Struktur dan semantic markup
- **CSS3**: Styling dan responsive design
- **JavaScript**: Dasar-dasar programming dan DOM manipulation

## Target Audience

Course ini cocok untuk: 
- Pemula yang baru memulai belajar programming
- Designer yang ingin belajar technical skills
- Freelancer yang ingin menambah web development skills

## Prerequisites

Tidak ada prerequisites khusus, hanya perlu:
- Komputer dengan internet
- Text editor (disarankan VS Code)
- Motivasi untuk belajar!

## Course Structure

Course ini terdiri dari 2 sections:

### Section 1: HTML & CSS Fundamentals (3 jam)
- HTML structure dan semantic tags
- CSS styling dan selectors
- Responsive design dengan Flexbox
- Basic layout techniques

### Section 2: JavaScript Basics (3 jam)
- JavaScript syntax dan data types
- Functions dan control flow
- DOM manipulation
- Event handling

Mari mulai perjalanan web development Anda!
