## Quick Start Guide

### Multi-File System Usage

```bash
# Basic usage - frontend + backend development
cd maguru/
claude --add-dir ../maguru-backend --add-dir ../shared-types

# Advanced usage - full-stack dengan infrastructure
claude --add-dir ../backend --add-dir ../infrastructure --add-dir ../shared-libs

# Performance optimized - large projects  
claude --add-dir ../services --scope module --concurrency 3
```
